Setup · the only step you do by hand · 10 min

Open Copilot

This is the only step without a prompt. Once Copilot is open, it does the rest of the setup with you, one prompt at a time.

  1. Install VS Code from code.visualstudio.com, then open it.

    VS Code is the app where you'll talk to Copilot and see your project's files.

  2. Open Copilot Chat.

    Click the Copilot icon at the top of the window, or press Ctrl Alt I (⌃ ⌘ I on a Mac).

  3. Sign in with GitHub.

    If you don't have a GitHub account, choose to create one when it asks. Use your NC State email, because that unlocks the free student plan later.

  4. Switch the chat to Agent mode.

    Use the dropdown under the chat box. Agent mode lets Copilot create files, run things and use the browser for you.

You're ready whenYou can type in Copilot Chat and the mode says Agent. Every step from here is copy and paste.

0:00 · 5 min

The big ideas

You already know the design process. AI just changes how fast each step goes. Every phase follows the same loop:

Brief→Generate→Review→Refine→Commit
  1. The agent reads files, not your mind.

    It only knows what's in your project and your message. Skills and briefs are how you hand it your thinking.

  2. Skills are know-how; prompts are the job.

    A skill teaches your agent how to do something well, on every project. A prompt tells it what to do now, on this project.

  3. Small steps beat big prompts.

    Ask for one screen or one feature at a time. Big asks give you big messes.

  4. Your taste is the spec.

    "Modern and clean" means nothing to an AI. "One loud red on warm gray, chunky headlines" means a lot.

  5. Commits are undo points.

    When something breaks, go back to your last commit instead of arguing with the AI.

How to plan any projectSplit it into steps you can check. For each step, decide the Goal (what's true when it's done), the Inputs (what the agent needs), the Prompt, the Check (how you'll know it worked) and when to Commit. Every phase here follows that pattern.

Ask your agent anything

This is the most useful prompt in the lesson. Ask any question in your own words, however non-technical, and your agent will answer in plain language, do the technical parts itself, and walk you through anything you have to click.

Try it nowAsk: "What is a commit, and how do I make one?" Then try: "What's the difference between my code on my laptop and my code on GitHub?"
Why it worksYou turned on Copilot's browser skill during setup, so it can open websites like GitHub, Vercel, Supabase and Figma, show you where to click and wait for you. The prompt also tells it never to hand you terminal commands.

Find your taste

Write down what "good" means for your Howl before anything gets built, so the agent designs toward your taste instead of its defaults.

Goal A taste profileCheck docs/taste-profile.md exists and sounds like you

Skills for this phase

  1. Install the taste-profile skill from the link above.
  2. Collect 3–5 references.

    Apps, sites or objects you love the look of. At least one shouldn't be an app: a gig poster, a sneaker, a menu.

  3. Fill in and paste the prompt below.
  4. Read the profile it writes.

    Rewrite any line that doesn't sound like you, then commit.

The ideaName what you can see, not how it feels. "Feels fresh" can't be built. "Lots of white space and one bright color" can.

Phase 3 · 0:28 · 22 min

Build your design system

Turn your taste into tokens: named values for color, type, spacing and shape. Change one token and the whole app changes, in light and dark mode.

Goal Tokens, light and dark mode, base components, Figma variablesCheck /design-system looks right and passes contrast in both modes
1. PrimitivesRaw values with no meaning yet.red-600 = #c11f2e
2. SemanticWhat a value is for. Dark mode swaps these.color-accent → red-600
3. ComponentsComponents only use semantic tokens.button → color-accent

Skills for this phase

  1. Install design-system-builder and color-contrast.
  2. Paste the design system prompt. Open /design-system and switch between light and dark mode.
  3. Paste the components prompt. Every button and input should show all its states.
  4. Bring it into Figma with the Figma prompt. Code stays the source of truth: change a token in code, import again, and Figma updates.
  5. Commit.
Behind?Paste this into Ask your agent anything: "Switch me to the checkpoint/03-design-system branch."

Skills for this phase

  1. Install ship-check.
  2. Paste the Vercel prompt. Copilot helps you create a Vercel account if you need one and publishes Howl. Say "done" after each step.

Wrap up · 1:52

Make your own skill

Every skill in the library has the same simple shape. Learn it, and you can turn anything you know into a skill your agent uses on every project.

Anatomy of a skill

---
name: spacing
description: Applies a consistent
spacing system. Use when building
layouts or when a screen feels
cramped or messy.
---

The label. The description is the most important line: agents read it to decide when to use the skill.

## My settings
- Density: comfortable

Your preferences. This is what makes a shared skill yours.

## Steps
1. …
2. …

The steps. Numbered, in order, each one checkable. Write them the way you'd brief a smart new teammate.

## Rules
- Measure, don't guess.

The guardrails. What the agent must always or never do.

Where skills liveOne folder per skill, each with a SKILL.md inside: .github/skills/spacing/SKILL.md. Copilot, Claude, Cursor and other agents read this format. A skill only loads when its description matches what you're doing, so you can install lots of them.

Toolkit

Vibe Annotations

Point at things on your app and say what's wrong, just like commenting in Figma. Then hand all your notes to your agent at once.

  1. Install it from the Chrome Web Store.
  2. Open your app's localhost link in Chrome. The extension turns itself on for local pages.
  3. Click any element and write a note. Be specific: "Too much space above the name," "This red is too loud here." You can also adjust sizes and colors right in the page.
  4. Copy all your notes from the extension and paste them into the prompt below.
Going furtherThe extension can also connect straight to some agents, so they read your notes automatically without copy-paste. Ask your agent: "Can you connect to Vibe Annotations?"

When something breaks

It will, and that's normal. For almost anything, paste what you see into Ask your agent anything. For the common cases:

What you seeWhat to do
Copilot changed way more than you askedAsk: "Undo everything since my last commit."
Copilot can't create or edit filesSet the chat mode to Agent, using the dropdown under the chat box.
Blank page or an errorAsk: "My page shows this: [paste or describe]. Fix it with the smallest change."
The localhost link won't loadAsk: "Start Howl again and give me the link."
You're behindAsk: "Switch me to the checkpoint branch for phase [number]."
The deploy failed, or the live site has no postsAsk: "My Vercel deploy failed (or my live site shows no posts). Use the ship-check skill to find out why."
